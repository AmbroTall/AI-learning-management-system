## 📝 PROJECT EXAMPLES

### Project 1: Smart Task Manager (Beginner)
**What Students Build:**
```
INPUT: "Investigate ransomware alert on SALES-PC-15"

AI SYSTEM:
1. Analyzes task complexity
2. Assigns priority (High - active threat)
3. Estimates time (2-3 hours)
4. Breaks into subtasks:
   - Isolate system (5 min)
   - Collect forensics (30 min)
   - Analyze malware (1 hour)
   - Document findings (30 min)
5. Assigns to appropriate analyst

OUTPUT: Prioritized, structured task ready for action
```

**Skills Learned:**
- Task analysis prompting
- Priority scoring
- Task breakdown
- Time estimation

---

### Project 9: Security Alert Triage Bot (Intermediate)
**What Students Build:**
```
INPUT: EDR Alert - Suspicious PowerShell from Outlook

AI BOT:
1. Enriches with context
   - User behavior baseline
   - Asset criticality
   - Historical patterns

2. Analyzes threat
   - Confidence: 85% malicious
   - Technique: Phishing → PowerShell dropper
   - Severity: High

3. Recommends actions
   - Isolate host immediately
   - Kill PowerShell process
   - Block C2 domain
   - Escalate to Tier 2

4. Routes to appropriate analyst
   - Assigned to: Senior SOC Analyst
   - Playbook: Malware Investigation
   - Estimated handling: 45 minutes

OUTPUT: Triaged, enriched, actionable alert
```

**Skills Learned:**
- Context enrichment
- Threat assessment
- Decision logic
- Automated routing

Hi Mark,

Thank you for your feedback on the Module 1 content. You were absolutely right — the lessons had drifted too far into cybersecurity-specific territory, which isn't appropriate for beginners on the AI Job Programme.

I've completely reworked Module 1 to focus on **practical, real-world prompt engineering skills** that any beginner can relate to — job hunting, meal planning, professional emails, side hustles, personal branding, and more. I've also designed the full programme structure across 4 modules. Here's the thinking:

| Module | Focus | What Students Walk Away With |
|--------|-------|------------------------------|
| **Module 1** | Prompt Engineering | Can communicate effectively with any AI tool |
| **Module 2** | AI Tools & Platform Features | Knows which tool to use when, and can use platform features like deep thinking, document download, and file upload |
| **Module 3** | AI Agents & Automation | Can build AI workflows, use agents, and automate tasks |
| **Module 4** | Capstone Project | Real portfolio piece — students choose **Coding with AI** or **Cybersecurity with AI** |

The cybersecurity and coding content now sits in **Module 4 as an elective** — students choose the path that excites them and build a real project applying everything from Modules 1–3.

### The Student Journey

1. **Module 1** — *"I can talk to AI effectively."* Students master prompt engineering through 30 hands-on lessons with real-world scenarios.

2. **Module 2** — *"I know which tools to use and how to use them."* Students explore the platform's advanced features (deep thinking, document download, file upload) and the wider AI tool ecosystem (ChatGPT, Claude, Gemini, Copilot, image generators, and more).

3. **Module 3** — *"I can make AI work for me."* Students learn about AI agents, build custom assistants, create automated workflows, and understand where AI is heading — preparing them for the future of work.

4. **Module 4** — *"I can build something real."* Students choose their specialisation and produce a genuine portfolio piece. Coding students build an AI-powered application. Cybersecurity students deliver a full security assessment. Both tracks demonstrate everything learned across the programme.
